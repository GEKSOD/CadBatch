# История изменений

Подробное описание каждого выпуска — в `docs/Release-X.Y.Z.md` и на странице [Releases](https://github.com/Geksod/CadBatch/releases).

## 0.8.9

- Порядок листов «как в чертеже»: чертежи — по имени с учётом чисел (01‑АР раньше 02‑КР), вкладки — в порядке AutoCAD (Лист2 раньше Лист10), рамки — рядами с допуском, затем слева направо: ряд А3‑А1‑А4, выровненный по низу, больше не перемешивается.
- Область поиска, список файлов и выделение действуют на один поиск и не сохраняются: они больше не скрывают молча другие чертежи.
- Скачанные обновления (около 85 МБ каждое) удаляются после установки и при запуске.
- Повторная установка после сбоя проходит: файлы прерванной попытки перезаписываются. На терминальном сервере учитываются только свои процессы — AutoCAD коллеги не мешает установке.
- При перевыпуске старый PDF не теряется: если он открыт, новый сохраняется рядом как «… (новый).pdf».
- «Разбить PDF на листы» работает через отдельный процесс при несовместимой библиотеке PDF в AutoCAD.
- Ошибка на одном листе больше не останавливает весь вывод; комплект с пропущенными листами сохраняется как «… (неполный).pdf», при отмене напечатанные страницы не теряются.
- Прогресс передаёт только изменившиеся статусы, таблица не перерисовывается целиком; контрольные суммы для журнала считаются в фоне, журнал пишется не чаще раза в 2 с.
- Окно подключения сообщает, если в AutoCAD загружен компонент прежней версии, вместо «Ждём AutoCAD…»; занятый командой AutoCAD сразу называется.
- Ведомость в UTF‑16 («Текст Юникод» из Excel) читается правильно; убрано предупреждение «Прототип: единицы геометрии…».

## 0.8.8

- Исправлена ошибка 0.8.6–0.8.7: поиск прерывался сообщением «Не удалось построить лист по внутренней рамке», если внутренняя рамка нарисована чуть неровно (в пределах допуска). Теперь лист строится точным прямоугольником по нижней стороне рамки, а рамку, по которой лист построить нельзя, поиск просто пропускает.

## 0.8.7

- Если часть листов нашлась, а остальные нарисованы в другом масштабе (например, листы с одной внутренней рамкой в 1:100 при списке масштабов «1»), проверка «не пропущены ли рамки» теперь пробует и распространённые масштабы и предлагает добавить недостающие листы. Мелкие прямоугольники в необычных масштабах по-прежнему не предлагаются: размер настоящего листа берётся с уже найденных.

## 0.8.6

- Находятся листы, у которых нарисована только внутренняя рамка ГОСТ, а край листа не нарисован или нарисован кусками (общая граница с соседним листом). Лист строится по рамке с полями 20 мм слева и 5 мм с остальных сторон; если край листа тоже найден, второй лист не появляется.
- Шифр с окончанием через дефис склеивается правильно: «112/10.21-КР-3.1».
- Пустые тексты без габаритов больше не засоряют диагностику сообщениями «eNullExtents».

## 0.8.5

- «Найти в выделенном»: выделите листы в AutoCAD — CAD Batch найдёт и сохранит в PDF только их. Если ничего не выделено, AutoCAD попросит выделить.
- «Порядок: по номеру листа» над таблицей: листы и страницы PDF идут по номерам (1, 2, …, 10; листы без номера — в конце). Выбор запоминается и применяется после каждого поиска.
- PDF создаётся в 2–3 раза быстрее: список бумаги PC3 читается один раз за сеанс, а не для каждого листа (это занимало около секунды на лист).
- Наименование листа читается из нижней графы штампа СПДС (раньше — из графы здания, одинаковой для всех листов); номер листа, «Листов» и стадия находятся надёжнее; шифр из нескольких частей склеивается без лишних пробелов. Листы с малым штампом последующих листов (форма 6) получают свой номер и наименование первого листа документа. Сохранённые старые зоны СПДС обновляются сами.
- «Показать в AutoCAD» больше не уменьшает развёрнутое окно AutoCAD: оно выходит на передний план в прежнем виде.

## 0.8.4

- Находятся рамки, нарисованные полилинией без «Замкнуть», если последняя точка совпадает с первой (раньше такие рамки пропускались).
- Если часть рамок нашлась, CAD Batch один раз проверяет, не пропущены ли другие (рамки из отдельных отрезков, на листах, во внешних ссылках), и предлагает их добавить.
- Ошибка «На выбранных слоях слишком много направлений отрезков» больше не прерывает поиск: на планах с тысячами линий проверяются основные направления, поиск рамок из отрезков стал быстрее, а сбой дополнительной проверки не портит основной результат.
- Мелкие прямоугольники (окна, таблицы), похожие на формат в необычном масштабе, больше не предлагаются как рамки.
- Окно «Штамп…» замечает размеры, введённые в единицах чертежа (18500 вместо 185 мм), и предлагает их пересчитать.

## 0.8.3

- Если с текущими настройками рамок нет, CAD Batch сам ищет шире — на листах, в блоках, отрезках, внешних ссылках, по штампу и в распространённых масштабах — и предлагает запомнить только нужные настройки. Масштаб выбирается для всего чертежа, чтобы А1 в 1:100 не превратился в А0×2 в 1:50.
- Если рамок нет совсем, окно объясняет, что проверить, и называет размеры самых крупных прямоугольников; это же попадает в диагностику.
- Новые профили ищут в модели и на листах, масштабы 1 и 100.

## 0.8.2

- Установщик обновляет файлы на месте, если папку нельзя переименовать (её отслеживает служба Autodesk, антивирус и т.п.) — причина ошибки «файл занят другим процессом» даже после перезагрузки.
- Установщик повторяет операции с занятыми файлами, называет программу, которая их держит, и предлагает закрыть забытые части CAD Batch; служебная копия больше не срывает установку; журнал установки.
- Фирменная иконка приложения, установщика и ярлыков; логотип в окнах.

## 0.8.1

- PDF кратных форматов и общий PDF снова создаются в AutoCAD, где загружена старая версия Microsoft.Extensions.Logging (например, AutoCAD 2023 «LMS Tech»): обработка PDF автоматически переходит в отдельный процесс.
- Проверка этой несовместимости добавлена в сборку.

## 0.8.0

- ИУЛ по ГОСТ Р 21.101-2020 с контрольной суммой CRC32 — рядом с каждым PDF или для готовых файлов.
- «Заменять файлы с тем же именем» при перевыпуске и кнопка «Повторить незавершённые».
- Журнал ошибок и «Справка → Собрать диагностику (ZIP)».
- Приложение больше не ждёт AutoCAD бесконечно: предел для коротких запросов и гарантированное завершение отмены.
- Компонент собирается для AutoCAD 2021–2024 одной сборкой и объявлен для отраслевых версий (`AutoCAD*`). 2021–2022 и Civil 3D / Architecture / Mechanical требуют проверки.
- Установщик удаляет копии прошлых версий после обновления и при удалении программы.
- Ведомость в CSV из русской Excel (Windows-1251) читается без искажений.
- Окно не обращается к диску по таймеру — не подвисает на сетевых папках.
- Версия задаётся в одном месте; одна инструкция (`docs/Start.md`), HTML и TXT собираются при выпуске.
- LICENSE, SECURITY.md, шаблон сообщения об ошибке, README со снимками экрана.
