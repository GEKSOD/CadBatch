# CAD Batch 0.8.5

**Только выделенные листы**

Выделите нужные листы в AutoCAD — например, рамкой выбора — и нажмите «Найти в выделенном» под кнопкой «Найти рамки». CAD Batch найдёт и сохранит в PDF только их, а не все сорок листов чертежа. Если ничего не выделено, AutoCAD попросит выделить листы. Следующее нажатие «Найти рамки» снова ищет по всему чертежу.

**Листы по порядку номеров**

Над таблицей появился выбор «Порядок: по номеру листа». Листы в таблице и страницы PDF идут по номерам: 1, 2, …, 10. Листы без номера ставятся в конец. Выбор запоминается и применяется после каждого поиска.

**PDF быстрее**

Больше всего времени при выводе уходило на подбор бумаги: для каждого листа CAD Batch заново перебирал все виды бумаги в PC3, а это около секунды на лист. Теперь список бумаги читается один раз за сеанс AutoCAD, поэтому PDF создаётся в 2–3 раза быстрее. Проверка бумаги перед печатью осталась прежней.

**Точнее номер и наименование листа**

- Наименование листа теперь берётся из нижней графы штампа, где оно стоит по ГОСТ Р 21.101. Раньше читалась графа выше, с названием здания, поэтому у всех листов было одно наименование. Название здания сохраняется отдельным полем «Объект» и подставляется, только если графа наименования пуста.
- Номер листа, «Листов» и стадия находятся, даже если текст стоит на границе ячейки. Шифр из нескольких частей склеивается правильно: «0502.1-2024-ВК.СО».
- Листы с малым штампом последующих листов (185×15) получают свой номер и наименование первого листа документа, например «Спецификация оборудования, изделий и материалов».
- Сохранённые зоны штампа прежних версий обновляются сами. Зоны, которые вы меняли, остаются как есть.

**«Показать в AutoCAD»**

Окно AutoCAD больше не уменьшается и не «прыгает»: оно выходит на передний план таким, каким было, в том числе на весь экран.

Обновитесь из приложения («Приложение → Проверить обновления…») или загрузите **CadBatch-Setup-0.8.5.exe**. Перед установкой закройте AutoCAD.
