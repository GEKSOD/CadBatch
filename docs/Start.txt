CAD Batch 0.5.0 — УСТАНОВКА И ЗАПУСК

1. В WINDOWS
Скачайте CadBatch-Setup-0.5.0.exe из раздела Releases проекта Geksod/CadBatch.
Сохраните работу и закройте AutoCAD и предыдущие окна CAD Batch.
Дважды щёлкните установщик, нажмите «Установить».
Установка выполняется для текущего пользователя. Права администратора не нужны.
На рабочем столе и в меню «Пуск» появится ярлык CAD Batch.
Отдельно устанавливать .NET или SDK не нужно: среда .NET 10 входит в приложение.

2. ПОДКЛЮЧЕНИЕ
Запустите полный AutoCAD 2023 или новее и откройте DWG.
Затем запустите CAD Batch ярлыком. Окно само найдёт запущенный AutoCAD за пару секунд.
Выберите нужный запущенный AutoCAD и нажмите «Подключиться».
Если подключений нет, перезапустите AutoCAD после установки компонента.
Если AutoCAD на ПК не установлен, приложение откроется, но обработка DWG будет недоступна.
AutoCAD LT не поддерживается. Интернет для самой обработки чертежей не требуется.

3. DWG → PDF
Окно ведёт по трём шагам.
Шаг 1 — слева выберите, где искать (Модель/Листы) и что считать рамкой. Нажмите «Найти рамки» или F5.
В «Точной настройке» можно задать слой, имя блока, масштаб и допуск.
Шаг 2 — в центре проверьте листы: снимите галочки с лишних, исправьте наименование и номер прямо в таблице.
Пробел отмечает выбранные строки, Ctrl+F — поиск по таблице, двойной щелчок показывает рамку в AutoCAD.
Шаг 3 — справа выберите «Как сохранить»: отдельные PDF, один общий PDF или группы по документам, форматам, шифрам.
Укажите папку и имя. Метки «Документ», «№ листа», «Формат» вставляют поля {Document}, {SheetNumber}, {Format}.
Цвет «Цвета чертежа» сохраняет цветную геометрию. Плоттер DWG To PDF.pc3 настраивается в «Плоттер и шаблоны».
Нажмите синюю кнопку внизу справа (Ctrl+Enter) и проверьте план. Если папка не выбрана, приложение предложит её выбрать.
После вывода нажмите «Открыть папку» в нижней строке окна.

«Показать» сворачивает приложение и показывает выбранную рамку в AutoCAD.
Чтобы вернуться, откройте CAD Batch через панель задач.
При выборе точек окно приложения временно скрывается и возвращается после выбора/Esc.

4. ОБНОВЛЕНИЯ
На начальном экране: «Проверить обновления…».
В основном окне: «Приложение → Проверить обновления…».
Приложение получает список выпусков только из GitHub Geksod/CadBatch.
Нажмите «Скачать обновление». Дождитесь подтверждения SHA-256.
Сохраните чертежи и полностью закройте AutoCAD.
Нажмите «Установить и перезапустить». CAD Batch завершится, установщик обновит
приложение и компонент AutoCAD, затем снова откроет приложение.
Настройки и сохранённые задания остаются в профиле пользователя; PDF не удаляются.
Проверку версии при запуске можно отключить на начальном экране.
Сбой интернета не мешает обычной работе с подключённым AutoCAD.

5. ПЕРЕНОСНОЙ КОМПЛЕКТ
Распакуйте CadBatch-Portable-0.5.0.zip в отдельную папку.
Запустите App/CadBatch.exe. При закрытом AutoCAD нажмите
«Установить» в строке «Компонент для AutoCAD», затем перезапустите AutoCAD.
После этого подключитесь из приложения. Установка компонента нужна один раз на ПК.
Для автоматической установки/обновлений предпочтителен EXE-установщик.

6. КОНТРОЛЬНАЯ ПРОВЕРКА
В AutoCAD создайте новый пустой DWG, в командной строке введите APPLOAD.
Загрузите samples/create-all-formats.lsp из комплекта документации.
В командной строке AutoCAD введите CBTESTFORMATS. Сохраните созданный DWG.
В CAD Batch: Модель вкл., Листы выкл., Полилинии вкл., слой CB_ALL_FORMATS,
масштаб 1, допуск 2, поиск масштаба по штампу выкл.
Ожидается 24 рамки. Выведите их отдельно и одним PDF с 24 страницами.
А4×9 должен иметь размер 1892 × 297 мм; А0×3 — 2523 × 1189 мм.
Проверьте цвет, ориентацию и контрольный отрезок 100 мм.

В первом выпуске отдельного приложения необходимо проверить подключение и печать
на настоящем AutoCAD: локальные автотесты не заменяют такую проверку.
При ошибке сохраните TXT-отчёт из папки вывода и текст CADBATCHINFO в AutoCAD.
Не размещайте рабочие чертежи и личные отчёты в публичном репозитории без необходимости.

7. УДАЛЕНИЕ
Windows → Параметры → Приложения → CAD Batch → Удалить.
Перед удалением закройте AutoCAD и CAD Batch. Настройки и пользовательские PDF сохраняются.
