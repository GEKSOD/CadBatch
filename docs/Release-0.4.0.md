# CAD Batch 0.4.0

Отдельное приложение Windows для работы с AutoCAD и пакетного вывода DWG в PDF.

- EXE-установщик, ярлыки рабочего стола/меню «Пуск», удаление через приложения Windows.
- Среда .NET 10.0.14 включена: дополнительная установка .NET не требуется.
- Подключение к запущенным AutoCAD через локальный канал текущего пользователя.
- Все инструменты основного окна доступны из отдельного приложения: рамки, штампы, PDF, шаблоны, Layout, ведомости, задания.
- Проверка GitHub Releases, загрузка установщика, проверка SHA-256, установка после закрытия AutoCAD и перезапуск.
- 24 стандартных/кратных формата, включая А4×9; отдельные или общий PDF.

Загрузите **CadBatch-Setup-0.4.0.exe**, закройте AutoCAD и установите программу. После установки запустите AutoCAD, откройте DWG и подключитесь из CAD Batch.

Полный AutoCAD 2023+ необходим. AutoCAD LT не поддерживается. Это первая тестовая сборка отдельного приложения: реальную печать/совместимость нужно проверить в установленном AutoCAD. Рабочие DWG не отправляются в интернет.
