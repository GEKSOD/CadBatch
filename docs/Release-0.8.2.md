# CAD Batch 0.8.2

**Установка больше не обрывается сообщением «Процесс не может получить доступ к файлу»**

Это сообщение появлялось, если во время установки какой-то файл прошлой версии был занят: чаще всего антивирус проверял только что распакованные файлы, иногда оставалось открытым окно прошлого установщика или скрытая часть CAD Batch.

- Главная причина, которая не проходила даже после перезагрузки: установщик заменял папки программы и компонента AutoCAD переименованием, а Windows не даёт переименовать папку, за которой следит другая программа (служба Autodesk, антивирус, синхронизация), даже если все файлы в ней свободны. Теперь в таком случае файлы обновляются прямо на месте, с резервной копией для отката.
- Установщик несколько секунд ждёт и повторяет попытку — обычно антивирус успевает отпустить файл.
- Если файл всё равно занят, установщик называет программу, которая его держит. Если это забытые части самого CAD Batch, он предлагает закрыть их одной кнопкой и продолжить.
- Служебная копия установщика больше не может сорвать установку.
- Ошибки установки записываются в журнал `%LOCALAPPDATA%\CadBatch\logs`.

**Новая иконка**

У приложения, установщика и ярлыков теперь фирменная иконка; логотип показан в окнах программы.

Загрузите **CadBatch-Setup-0.8.2.exe**, закройте AutoCAD и установите программу.
