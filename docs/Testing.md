# Проверка CAD Batch

Сначала выполните инструкцию Start.md и создайте контрольный DWG на 24 формата через samples/create-all-formats.lsp / CBTESTFORMATS.

Проверьте:

- Подключение к нужному AutoCAD из отдельного приложения; несколько процессов AutoCAD.
- 24 рамки, отдельные PDF и один PDF с 24 страницами; цвет и размеры А4×9/А0×3.
- «Показать», вложенный блок, поворот, масштаб 100, выбранная область, XCLIP.
- Передвижение рамки после поиска: старый результат должен потребовать повторного поиска.
- Загрузка/сохранение шаблонов, полей штампа и задания; отмена и возобновление вывода.
- Layout/экспорт/ZIP/ведомость; Undo изменений DWG, Esc при выборе точки.
- Проверка обновлений; повреждённый установщик не запускается; установка при открытом AutoCAD блокируется.
- Закрытие/повторное подключение, перезапуск приложения, Windows DPI 100/125/150%.

При ошибке сообщите версию CAD Batch/AutoCAD, действие и текст ошибки. Приложите обезличенный пример или отчёт по необходимости. Не публикуйте исходные рабочие чертежи и личные пути автоматически.

Локальные проверки: геометрия/PDF, сериализация рамок/штампа, групп PDF, ограничения протокола, сервер обновлений и SHA-256, реальные named pipes, запуск WPF под CLR 4.8 и .NET 10. Печать в настоящем AutoCAD остаётся отдельной обязательной проверкой.
