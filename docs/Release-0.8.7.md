# CAD Batch 0.8.7

**Находятся все листы, даже в разных масштабах**

В чертеже часть листов может подтверждаться штампом, например в 1:100 или 1:50, а у другой части нарисована только внутренняя рамка, и масштаб у них берётся из списка масштабов. Если в списке был только масштаб 1, CAD Batch находил первые листы и не находил вторые.

Теперь, если часть листов нашлась, проверка «не пропущены ли рамки» пробует и распространённые масштабы. Найдя недостающие листы, она предлагает: «Ещё 3 рамок текущие настройки пропускают… добавить масштаб 1:100». После «Добавить и запомнить» в таблице будут все листы, а масштаб запомнится для следующих поисков.

Мелкие прямоугольники, например таблицы, которые совпадают с форматом только в необычном масштабе, по-прежнему не предлагаются: размер настоящего листа берётся с уже найденных листов.

Обновитесь из приложения («Приложение → Проверить обновления…») или загрузите **CadBatch-Setup-0.8.7.exe**. Перед установкой закройте AutoCAD.
