# Публикация выпуска

1. Измените версию в Directory.Build.props, ProductInfo и PackageContents.xml.
2. Выполните сборку и проверки, включая tests, bridge smoke и настоящий AutoCAD.
3. Запустите scripts/package.ps1. По умолчанию собирается автономное Windows x64 приложение с .NET 10.0.14.
4. Проверьте EXE через --smoke в пустом временном каталоге, переносной архив и список SHA256SUMS.txt.
5. Создайте тег vX.Y.Z и GitHub Release. Загрузите CadBatch-Setup-X.Y.Z.exe, переносной ZIP и SHA256SUMS.txt.
6. Выпуск должен быть опубликованным, с prerelease=false. Updater использует releases/latest и встроенный GitHub digest SHA-256.

Не заменяйте файлы уже опубликованного выпуска: создавайте новую версию. В GitHub размещаются только собственные исходники, документация и сборки; личные DWG/отчёты, SDK-кэш и сторонние установщики исключены.

Для публикации с ПК владельца можно использовать tools/github-release.py. Скрипт читает авторизацию из Git Credential Manager; токены не записываются в репозиторий. Не указывайте ключи или пароли в командной строке.
