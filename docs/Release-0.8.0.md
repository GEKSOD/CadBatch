# CAD Batch 0.8.0

**Для экспертизы**

- **ИУЛ по ГОСТ Р 21.101-2020.** Включите «Создавать ИУЛ для экспертизы» — рядом с каждым PDF появится информационно-удостоверяющий лист «…-УЛ.pdf» с контрольной суммой CRC32, размером и датой файла. Фамилии разработчика, проверяющего, нормоконтролёра и ГИП задаются один раз. Для уже готовых файлов (PDF, DWG и других): «Ещё → ИУЛ для готовых файлов». Сверьте форму с требованиями вашей экспертизы.

**Перевыпуск**

- «Заменять файлы с тем же именем»: при перевыпуске старый PDF заменяется, а не появляется копия «(2)».
- «Повторить незавершённые»: если вывод прервался из-за ошибки или отмены, одной кнопкой выводятся только листы без готового PDF.

**Надёжность**

- Приложение больше не ждёт AutoCAD бесконечно: если AutoCAD не отвечает, появляется понятное сообщение с кнопкой «Подключиться снова», а отмена всегда завершается.
- Журнал ошибок и «Справка → Собрать диагностику (ZIP)»: один файл с версиями, журналом и настройками для отправки разработчику. Чертежей в нём нет.
- Установщик удаляет копии прошлых версий после обновления и при удалении программы (раньше оставалось около 200 МБ на каждое обновление).
- Ведомость в CSV из русской Excel (кодировка Windows-1251) загружается без искажения кириллицы.
- Окно не обращается к диску пять раз в секунду и не подвисает на сетевых папках.

**Совместимость**

- Компонент собран для AutoCAD 2021–2024 одной сборкой и объявлен для отраслевых версий (Civil 3D, Architecture, Mechanical). На AutoCAD 2021–2022 и отраслевых версиях проверка ещё не проведена — сообщайте о результатах.

**Прочее**

- Лицензионные условия (LICENSE), README со снимками экрана, история изменений, шаблон сообщения об ошибке.

Загрузите **CadBatch-Setup-0.8.0.exe**, закройте AutoCAD и установите программу. Настройки и комплекты сохраняются.
