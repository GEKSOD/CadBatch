# CAD Batch 0.5.0

Новый интерфейс: приложение ведёт по шагам, и сразу видно, что делать дальше.

- **Три шага в главном окне:** «Найдите рамки» → «Проверьте листы» → «Сохраните PDF». Номера шагов подсвечиваются по мере работы. Если листов нет, в центре показано, с чего начать.
- **Окно подключения:** чек-лист «компонент → AutoCAD → связь» обновляется сам каждые 2 секунды и замечает запуск AutoCAD. Рядом с невыполненным шагом есть кнопка «Установить» или «Запустить». Интерфейс можно открыть без AutoCAD кнопкой «Посмотреть демо».
- **Вывод PDF:** все пять режимов в одном списке «Как сохранить». Поля имени файла вставляются кнопками. Рядом с кнопкой вывода написано, чего не хватает. Если папка не выбрана, приложение предложит её выбрать. После вывода появляется кнопка «Открыть папку».
- **Таблица:** живой поиск (Ctrl+F); пробел отмечает выбранные строки; формат показан меткой. Справа — схема выбранного листа со штампом.
- **Горячие клавиши:** F5 — найти рамки, Ctrl+Enter — вывести PDF, Esc — отмена. В меню «Справка» — краткое руководство.
- **Диалоги:** современные окна вместо стандартных окон Windows. План вывода сначала показывает главное: число файлов, папку и плоттер.

Исправлено:

- Неверное число вызывало непонятную ошибку .NET на английском; теперь понятное сообщение на русском.
- В демо-режиме в шапке было написано «Нет подключения».
- Вывод без выбранной папки заканчивался ошибкой.
- Поля имени дописывались в конец без разделителя.
- Таблица при каждом обновлении сама выделяла первую строку.
- Проверка скачанного обновления подвешивала окно.
- Загрузка или сохранение шаблона с пустым или несуществующим именем вызывали ошибку файла.
- После переустановки компонента оставалась лишняя резервная папка.

Загрузите **CadBatch-Setup-0.5.0.exe**, закройте AutoCAD и установите программу. Настройки и задания из 0.4.0 сохраняются.

Нужен полный AutoCAD 2023 или новее; AutoCAD LT не поддерживается. Логика поиска рамок и печати не менялась, но новый интерфейс ещё не проверен в установленном AutoCAD — сообщайте о проблемах в Issues.
