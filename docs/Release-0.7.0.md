# CAD Batch 0.7.0

**Новые редакторы — такие же понятные, как главное окно**

- «Печать по форматам» переделан: слева список форматов, справа обычная форма — принтер, бумага, стиль, цвет, масштаб, поворот, смещение. Пустое поле означает «как в общих настройках». Кнопка «Взять список из AutoCAD» подставляет принтеры, бумагу и стили. Шаблоны сохраняются и загружаются там же.
- «Поля штампа» переделан: зоны чтения нарисованы на схеме штампа 185 × 55 мм, их видно сразу. Зону можно выбрать щелчком по схеме, координаты меняются в форме. Есть готовые наборы СПДС и ЕСКД.
- Оба окна увеличиваются вместе с выбранным размером текста.

**Ведомости**

- Ведомость можно сохранить в Excel через «Ещё».
- Исправленные в Excel или CSV названия, номера, шифры и ревизии возвращаются в CAD Batch: «Ещё → Загрузить названия и номера из ведомости». Перед применением показывается список «было → стало».
- Группировка ведомости по нескольким полям: например «Шифр; Формат» даёт вложенные заголовки.
- В ведомость можно добавить столбец «№» — по нему строки сопоставляются точно.

**PDF**

- Новый флажок «Повторять листы в PDF по числу копий» («Плоттер и шаблоны», расширенный режим): лист с тремя копиями появится в PDF три раза.

Загрузите **CadBatch-Setup-0.7.0.exe**, закройте AutoCAD и установите программу. Настройки и задания сохраняются.

Нужен полный AutoCAD 2023 или новее; AutoCAD LT не поддерживается. Поиск рамок и печать в AutoCAD не менялись; новые окна проверены без AutoCAD.
