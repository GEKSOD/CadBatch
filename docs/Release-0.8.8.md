# CAD Batch 0.8.8

**Исправлена ошибка «Не удалось построить лист по внутренней рамке»**

В версиях 0.8.6–0.8.7 поиск мог прерваться этим сообщением, и тогда не находился ни один лист. Так случалось, если внутренняя рамка листа нарисована чуть неровно: углы отличаются на тысячные доли единицы, в пределах допуска поиска.

- Теперь лист строится как точный прямоугольник по нижней стороне внутренней рамки, с полями 20 мм слева и 5 мм с остальных сторон.
- Если по какой-то рамке лист построить нельзя, поиск её пропускает и продолжает работу.

Обновитесь из приложения («Приложение → Проверить обновления…») или загрузите **CadBatch-Setup-0.8.8.exe**. Перед установкой закройте AutoCAD.
