# CAD Batch 0.8.1

**Исправлено: PDF кратных форматов и общий PDF не создавались в некоторых AutoCAD**

В части установок AutoCAD (например, AutoCAD 2023 «LMS Tech») внутри AutoCAD уже загружена старая версия библиотеки журналирования (Microsoft.Extensions.Logging 1.1.1). Из-за этого вывод останавливался с ошибкой «Не удалось загрузить тип "Microsoft.Extensions.Logging.Abstractions.NullLoggerFactory"» на листах кратных форматов (А3×3, А4×3 …) и при сборке общего PDF.

Теперь, если обработка PDF внутри AutoCAD натыкается на такую несовместимость, CAD Batch автоматически выполняет её в отдельном небольшом процессе со своими библиотеками. В обычных установках всё работает как раньше, без потери скорости.

Исправление проверено на воспроизведении этой же ошибки: программа с тем же перенаправлением библиотеки на версию 1.1.1 падала с тем же сообщением, а с исправлением создаёт и общий PDF, и PDF точного размера.

**Если AutoCAD показывает «Следующие комбинации, заданные для поиска плоттеров, признаны неверными»**

Это предупреждение самого AutoCAD: в путях поиска плоттеров оказались ярлыки (.lnk). Откройте в AutoCAD «Параметры → Файлы → Путь доступа к файлам поддержки принтеров → Путь поиска файлов описания принтеров» и удалите строки, которые указывают на ярлыки (.lnk). После этого окно перестанет появляться.

Загрузите **CadBatch-Setup-0.8.1.exe**, закройте AutoCAD и установите программу.
