# CAD Batch 0.8.6

**Листы с одной внутренней рамкой**

Во многих чертежах нарисована только внутренняя рамка листа по ГОСТ, а край листа отсутствует или собран из обрывков, общих с соседним листом. Раньше CAD Batch такие листы не находил и писал «Рамки не найдены».

- Теперь лист строится по внутренней рамке: к ней добавляются поля, как по ГОСТ, — 20 мм слева и 5 мм сверху, справа и снизу. PDF получается на весь лист нужного формата, например А3×3 или А2.
- Если в чертеже нарисованы и край листа, и внутренняя рамка, лист остаётся один.
- В таблице такие листы отмечены в колонке «Источник»: «внутренняя рамка».
- Шифр с окончанием через дефис склеивается правильно: «112/10.21-КР-3.1».
- Пустые тексты без габаритов больше не засоряют диагностику сообщениями «eNullExtents».

Обновитесь из приложения («Приложение → Проверить обновления…») или загрузите **CadBatch-Setup-0.8.6.exe**. Перед установкой закройте AutoCAD.
