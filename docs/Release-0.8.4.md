# CAD Batch 0.8.4

**Находятся все рамки чертежа**

- Рамки, нарисованные полилинией без «Замкнуть», теперь находятся, если последняя точка вернулась в первую. Именно поэтому в некоторых чертежах находилась только часть листов.
- Если часть рамок нашлась, CAD Batch один раз проверяет, не пропущены ли другие: рамки из отдельных отрезков, на листах, во внешних ссылках. Найденные он предлагает добавить и запомнить нужные настройки.
- Сообщение «На выбранных слоях слишком много направлений отрезков» больше не прерывает поиск. На планах с тысячами линий проверяются основные направления, поиск рамок из отрезков стал быстрее, а сбой дополнительной проверки не мешает основному результату.
- Мелкие прямоугольники, например окна или таблицы, которые в необычном масштабе совпадают с форматом, больше не предлагаются как рамки.
- Окно «Штамп…» замечает, если ширину штампа ввели в единицах чертежа (например, 18500 вместо 185 мм), и предлагает пересчитать.

Обновитесь из приложения («Приложение → Проверить обновления…») или загрузите **CadBatch-Setup-0.8.4.exe**.
