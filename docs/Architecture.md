# Архитектура

CAD Batch.exe — отдельный WPF-процесс. Поддерживаемый AutoCAD загружает пользовательский CadBatch.bundle при запуске. DLL выполняет обращения к CAD API в контексте AutoCAD; локальный канал передаёт типизированные команды/результаты, прогресс и отмену.

Named pipes ограничены текущим пользователем Windows. Каждая регистрация содержит случайное имя/токен сеанса; произвольные команды AutoCAD и исполняемый код по протоколу не передаются. Геометрия перепроверяется нативным адаптером перед операцией.

Обновления: только Geksod/CadBatch на GitHub, опубликованные стабильные Releases, установщик с версией в имени. Проверяются URL, размер и GitHub SHA-256 digest. Загрузка не означает установку: пользователь запускает её явно, предварительно закрыв AutoCAD. Установщик сохраняет настройки, использует временные каталоги и резервные копии.
