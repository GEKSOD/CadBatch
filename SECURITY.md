# Безопасность

Если вы нашли уязвимость в CAD Batch, не публикуйте её в открытых Issues.

Сообщите о ней закрыто: на странице репозитория откройте вкладку **Security → Report a vulnerability**
(https://github.com/Geksod/CadBatch/security/advisories/new). Опишите версию CAD Batch, шаги
воспроизведения и возможные последствия.

Поддерживается только последняя опубликованная версия: исправления выходят новым выпуском,
который приложение предлагает установить само.

Как устроена защита:

- обновления скачиваются только из выпусков этого репозитория и проверяются по контрольной сумме SHA-256 до запуска установщика;
- связь приложения с AutoCAD идёт по локальному каналу текущего пользователя с одноразовым ключом, без сети;
- чертежи и PDF никуда не отправляются; интернет нужен только для проверки обновлений.
